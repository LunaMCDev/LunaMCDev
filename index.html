Two editions, one codebase

Start with a Crescent.
Grow into a Full Moon.

Crescent is a complete plugin you can run forever. Full Moon adds the tools large servers need. Upgrading means swapping one jar: your configs and data stay as they are.

Crescent

Free · for every server
  • The full core of every plugin, no trial and no time limit
  • Simple YAML config with comments on every option
  • Every menu, command and PlaceholderAPI placeholder you need to run it
  • Same performance and dupe protection as Full Moon
  • Works on Spigot, Paper, Purpur and Folia, 1.8.8 to latest

Full Moon

Premium · for growing servers and networks
  • In-game editors, so you never have to touch YAML
  • More content: animations, objectives, actions, events
  • MySQL, Redis and sync across a whole network
  • Analytics, logs and Discord webhooks
  • Deeper links with every other Moon plugin

Questions

Good to know.

Is Crescent really free forever?

Yes. Crescent isn't a trial or a demo. It's a complete plugin with no time limits and no nag screens. Many small servers will never need anything else.

How do I upgrade from Crescent to Full Moon?

Replace the Crescent jar with the Full Moon jar and restart. Configs and player data are read as they are, so there's nothing to migrate.

Which server software and versions are supported?

Spigot, Paper, Purpur, Pufferfish and Folia, from 1.8.8 up to the latest release, including the year-numbered versions. Java 8 or newer.

Do Bedrock players work?

Yes, through Geyser and Floodgate. Some Full Moon plugins, starting with MoonPrison, also show native Bedrock forms instead of chest menus.

Do I need every Moon plugin?

No. Every plugin works on its own. Installing more of them unlocks the integrations shown in the constellation above.

What happens if the licence server is down?

Nothing visible to players. Full Moon keeps running and logs a warning in the console. A network problem will never take a paying server offline.

Will there be a bundle?

Yes. The Moon Suite bundle will include every Full Moon plugin at a large discount. There will also be smaller Prison and Survival packs.

Where do I get support?

In the Moon Suite Discord. Each plugin has its own channel, and every release has a wiki page and a changelog.
